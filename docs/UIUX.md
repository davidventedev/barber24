# Barber24 — UI/UX

## Principios
- Mobile first, bottom navigation en móvil / sidebar en desktop
- Fondo negro, acento `#EAC452`
- Tipografía display: Bebas Neue · UI: DM Sans
- Sin cards innecesarias; paneles solo para listados/forms
- Microinteracciones: fade-up en login/landing, hover en features

## Pantallas clave
1. Landing SaaS (hero brand-first)
2. Login (logo Barber24 + email/Google)
3. Dashboard barbero / dueño
4. Calendario semanal
5. Clientes / Métricas
6. Config tienda (tabs)
7. Formulario público `/b/{slug}/`
8. Superadmin
9. Historial cliente
